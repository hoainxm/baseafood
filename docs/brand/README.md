# Logo Baseafood

- `baseafood-logo-original.jpg` — logo gốc rõ nét chủ dự án gửi 2026-11-03 (824×482, nền trắng). Mọi bản dưới đây làm ra từ file này.

- `public/invoice-logo.jpg` — logo in trên Invoice / Packing list PDF (480 px, nền trắng, JPEG ~32 KB cho file PDF nhẹ). Dùng ở `src/features/export-planning/invoiceDocument.ts` → `src/lib/exportInvoicePdf.ts`.
